# Our Family Tree

An interactive family heritage project preserving our family's roots, ancestry, and generations for the future.

## About
This project documents our family lineage through an interactive website, allowing family members to explore ancestors and their descendants.

## Built With
- HTML
- CSS
- JavaScript

## Purpose
To preserve our family history and pass our heritage on to future generations.

## Privacy
This project is intended to preserve family heritage. Personal information about living family members should only be published with their permission.
